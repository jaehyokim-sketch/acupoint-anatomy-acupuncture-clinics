## 📌 개요 (Overview)
본 저장소는 **경혈 해부생리학 실체 판명 로직 프레임워크(Framework v2.7, ARI v3.0)**에 기반하여 분석·정리된 전문 학술 리포트, 3대 침구 원전 비교 고증 및 동의보감 두통 임상 매트릭스를 온라인에 인터랙티브하게 서비스하기 위한 공식 웹 아카이브입니다.

## 📂 주요 수록 콘텐츠 (21편 전문 리포트)

### 1. 개별 경혈 해부생리학 실체 판명 보고서 (9개 핵심 혈위, 9편)
- **ST36 족삼리 (足三里)**: ARI-Core 77.5 (B 개연). 깊은종아리신경·앞정강동정맥, 미주-부신 축 기전은 마우스 한정(B-Check 9/12)
- **LU06 공최 (孔最)**: 표준 공최 71.2 (B) / 사와다식 치질 반응점 35 (D·H). '孔最治痔' 讹传 반론에 따라 치질 주치 분리
- **LU03 천부 (天府) · LU04 협백 (俠白) 통합**: 고전 위팔동맥 박동점 56.2·62.5 (C·H) vs WHO 가쪽 근육점 41.2·43.8 (D·H), Δ≈28mm 분기, 고전 우위
- **GB39 현종 (懸鐘)**: 고전 앞정강동맥 맥동점 51.2 (D·H) vs WHO 비골 앞모서리 55 (C), Δ≈20~35mm 분기. 구판 《通考》 인용 삭제
- **GV20 백회 (百會)**: ARI-Core 71.2 (B, 가중치 민감). 두피·머리덮개널힘줄 층, 반사 기전은 가설(B-Check 6/12)
- **BL02 찬죽 (攢竹)**: ARI-Core 81.2 (B), SI 0 ⚠(《医学入门》 禁用针灸). 도르래위신경·동정맥
- **GB21 견정 (肩井)**: ARI-Core 67.5 (C), SI 0 ⚠ 기흉 고위험. 고전·WHO 분기 철회
- **PC09 중충 (中衝)**: ARI-Core 67.5 (C), SI 100. 고유바닥쪽손가락신경(감각) 말단, 정혈 기전은 가설
- **ST36 vs GB21 비교 분석 (`ST36_GB21_Comparative_Analysis_Report.html`)**: 두 보고서 확정 결과의 비교 요약

## 🔄 v2.7 개정 (2026-10-04)
- 모든 경혈 보고서를 **ARI v3.0**(ARI-Core 3요인 + 안전지수 SI, 5단계 루브릭, 비보상형 게이트)으로 **독립 2인 이중 채점** 후 재판정했다. 구판 v2.6 점수(90점대 'Class A', '실체성 확정')는 비교할 수 없다.
- 원문 대조에서 확인되지 않은 《针灸腧穴通考》 인용을 삭제하고 실제 원문으로 교체했다. 생의학 근거는 Layer A 논문 `papers.id`와 Layer B 참조 ID(B1~B4)로 인용한다.
- 문헌 고증 보고서의 '100% 일치·입증' 표현을 원전 대조 수치로 정정했다.
- HTML 도식(상자 그림·Mermaid)은 글꼴 폭 차이로 선이 어긋나지 않도록 PNG 이미지로 내장했다.

## 🛠 기술 및 호스팅 스택
- **호스팅**: GitHub Pages (`main` branch root `/`)
- **디자인 시스템**: Vanilla CSS (Dark Glassmorphism, Responsive Grid)
- **타이포그래피**: Google Fonts (Noto Sans KR, Inter, Outfit, JetBrains Mono)
- **수식 렌더링**: KaTeX CDN
- **보고서 생성**: `build_report_html.py` (마크다운 → HTML, 도식 PNG 내장)
- **인터랙티브 기능**: Vanilla JS 실시간 검색 및 다중 카테고리 필터링
